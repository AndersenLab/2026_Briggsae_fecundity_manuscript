# Raw Data

This directory contains the raw data files used for the *Caenorhabditis briggsae* fecundity study. These files include manual sentinel strain counts, automated counts for all strains, strain information, and image-analysis validation data.


### 1. Manual Sentinel Strain Counts

CSV files containing manual fecundity counts for sentinel strains, performed independently by three experimentalists over five days (Days 1–5).

The files are organized by assay and day

- Assay1_sentinelstrains_Day1 to Assay1_Sentinelstrains_Day5
- Assay3_sentinelstrains_Day1 to Assay3_Sentinelstrains_Day5
- Assay4_sentinelstrains_Day1 to Assay4_Sentinelstrains_Day5
- Assay5_sentinelstrains_Day1 to Assay5_Sentinelstrains_Day5
- Assay6_sentinelstrains_Day1 to Assay6_Sentinelstrains_Day5
- Assay7_sentinelstrains_Day1 to Assay7_Sentinelstrains_Day5

Each file contains the manual counts recorded for a specific assay and day by three analysts.

### 2. Automated Image-Analysis Data

- `automation_raw_data_A_1_2_7.csv` - automated counts for assays 1, 2, and 7
- `automation_raw_data_A_3_4_5_6.csv` - automated counts for assays 3, 4, 5, and 6

Raw data files associated with automated counts. 

### 3. Strain Information and Relatedness

- `cb_allout25_strains.txt` — List of best mapping panel.
- `C.briggsae_relatednessgroups.csv` — Relatedness group information for the assignments for *C. briggsae* strains.
- `Cbriggsae_WI_strain_info.csv` — *C. briggsae* strain information.

### 4. Replicate Information

- `saved_replicates.csv` — Replicated that were saved used in the "Saved replicate" analysis.

### 5. Image-Analysis Validation Data

- `Trial1_Precision_recall.csv`
- `Trial2_Precision_recall.csv`

Data from two trials used to evaluate the precision and recall of the automated counting pipeline.
